# Струм ОК ⚡

Публічний Telegram-бот для сповіщень про графіки відключення електроенергії в Івано-Франківську.

Telegram: `@Svitlookay_bot`

## Поточна версія
- `/start`
- вибір підчерги 1.1–6.2
- збереження підчерги
- меню «Стан зараз», «Сьогодні», «Завтра»
- увімкнення/вимкнення сповіщень
- посилання на офіційний сервіс визначення підчерги

Наступний етап — автоматичне отримання та відстеження змін офіційного графіка Прикарпаттяобленерго.

## Безпека
Токен Telegram не зберігається в репозиторії. На сервері він задається змінною середовища `BOT_TOKEN`.
